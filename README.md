# ica-forge

> 手写 **独立成分分析 (ICA) / FastICA** —— 盲源分离的数学核心。零依赖、单文件 HTML，浏览器内一键自检 + 原生 Node 无头 **16/16 不变量全绿**。

`ica-forge` 是 **forge 系列**（纯 JS 单文件手写 ML 算法实验室）的第 15 个作品。它把「从混合信号中盲分离出独立源」这一过程完整手写实现：中心化 → 协方差 → **Jacobi 特征分解** → 白化 → **FastICA 定点迭代**（kurtosis / tanh 两种对照函数，deflation / symmetric 两种模式），全部无外部依赖、无构建。

打开 `index.html` 即可运行：左侧控制对照函数与模式，右侧 8 项实时自检 + 源/恢复散点 + 定点收敛。

## 算法

给定观测 `X = A·S₀`（`A` 未知可逆混合矩阵，`S₀` 各行相互独立且非高斯），目标：仅凭 `X` 恢复 `S₀`（至置换与符号）。

| 步骤 | 数学 |
|---|---|
| 中心化 | `Xc = X − E[X]` |
| 协方差 | `C = (1/N)·Xc·Xcᵀ` |
| 特征分解 | `C = V·diag(λ)·Vᵀ`（**Jacobi 循环旋转**，手写） |
| 白化 | `Z = K·Xc`，`K = V·diag(λ^(−1/2))·Vᵀ` ⇒ `cov(Z) = I` |
| FastICA 定点 | `w ← E[Z·g(wᵀZ)] − E[g′(wᵀZ)]·w`，再正交化 + 归一化 |

对照函数 `g`：
- **kurtosis**：`g(u)=u³`，`g′(u)=3u²`（最大化 |峰度|，捕捉超/次高斯源）
- **tanh**：`g(u)=tanh(u)`，`g′(u)=1−tanh²(u)`（稳健，对离群点不敏感）

两种解混策略：
- **deflation（收缩）**：逐个抽取成分，每步对已得 `w_j` 做投影剔除。
- **symmetric（对称）**：所有成分同步更新，用 `W ← (W·Wᵀ)^(−1/2)·W` 正交化。

参考：A. Hyvärinen & E. Oja, *Independent Component Analysis: Algorithms and Applications* (2000)；Hyvärinen, *Fast and Robust Fixed-Point Algorithms for ICA* (1997)；Hyvärinen, Karhunen & Oja, *ICA* (2001)。

## 三个「真坑」（手写时踩到的）

1. **`W·K·A` 不是置换矩阵**，而是 `置换 × diag(1/√var(源))`——因为各源方差不等。必须先按列归一化，才能验证「有符号置换」这一不变量。直接判 `≈置换` 会误报失败。
2. **FastICA 定点可 ±w 振荡**：`w ↦ −w` 也是合法不动点，导致 ‖Δw‖ 在 2 附近震荡不收敛。判据须取 `min(‖w_new−w‖, ‖w_new+w‖)`。
3. **收敛计数别覆盖最终 delta**：把 `conv[p]` 同时用作「末次 Δ」和「迭代次数」会互相踩踏，须分开存储。
